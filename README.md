# 瓦房店推倒胡

这是一个可在微信开发者工具中打开的原型，包含：

- 首页、创建私人房、四人牌桌和规则说明页。
- 标准瓦房店推倒胡预设及局数、底分、吃牌、混和大牌开关。
- 独立的 CommonJS 规则引擎，可在 Node.js 中测试。

## 打开方式

1. 打开微信开发者工具。
2. 导入本目录，AppID 选择测试号或替换 `project.config.json` 内的 `appid`。
3. 编译后，从首页创建房间并进入牌桌原型。

## 规则引擎测试

```sh
node utils/mahjong-engine.test.js
```

## 现阶段边界

本项目是前端交互原型和规则引擎基础，不包含正式实时服务。生产版必须补充：服务端权威洗牌与状态机、WebSocket 同步、微信登录校验、断线重连、数据访问控制、隐私政策和审核材料。

金蛋、放喜和彩杠特意未进入房间开关，因为尚无本地一致、可验证的触发与积分规则。

已确认翻混映射：万、筒、条一至九循环；风牌按东→西→南→北→东循环；中→发→白→中循环。混可代替任意牌组成顺子、刻子、对子，也可代替缺牌参与吃、碰；不能打出，不能参与明杠、暗杠或补杠。翻开的指示牌留在牌外。开局庄家第一次掷骰定位牌墙并翻指定墩的上张，第二次由第一次选中的牌墙所属玩家掷骰以确定开牌位置。已接入联机：以庄家为1，按行动方向数第一次点数选牌墙，从该家右侧数对应墩翻上张；同一家掷第二次，两次点数相加跳过对应墩后开牌，超过17墩时继续下一段牌墙。服务端生成两次骰子并向四人广播结果。房间默认开启混，可在创建时关闭。
