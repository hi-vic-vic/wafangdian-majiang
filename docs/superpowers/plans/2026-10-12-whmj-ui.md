# 威海麻将 UI 复用实施清单

**Goal:** 用指定本地 whmj.cocos2d_client 的视觉和图片改造首页、建房页与横屏实时牌桌。

**Architecture:** 原生微信小程序 WXML/WXSS 重建布局，复用上游图片。原有 Go 对局服务、瓦房店规则与 WebSocket 消息保持现有契约。

**Tech Stack:** 微信小程序、CommonJS、Node.js 测试。

**Spec:** 本任务中用户已确认的首页、建房、实时牌桌视觉改造及横屏牌桌方案。

## Constraints

- 仅复制使用到的资源，保留 Apache-2.0 和来源清单。
- 首页、建房保持竖屏，实时牌桌独立配置 landscape/custom navigation。
- 四个座位按自己的 seat 旋转为下、右、上、左，不泄露其他玩家手牌。
- 已有准备、出牌、吃碰杠胡、邀请、解散投票、结算和重连继续可用。
- 不迁移 Cocos 引擎或服务端，不提交或推送；当前目录没有 Git 仓库。
